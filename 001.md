# **1\. Product Requirement Document (PRD)**

**Project Name:** New Era Support Ltd – Corporate Web Platform

**Target Audience:** UK Healthcare & Housing Providers (Clients), Job Seekers (Candidates), Internal Operations/Compliance Team

**Objective:** Deliver a high-converting, compliant, and accessible web platform to facilitate staffing requests, job applications, and agency credibility.

### **Key Product Goals & Success Metrics**

* **Lead Generation:** Simple, high-conversion inquiry funnel for B2B care providers.  
*   
* **Applicant Capture:** Frictionless onboarding flow with document/CV upload for UK care & hospitality workers.  
*   
* **Compliance & Trust:** Clear presentation of UK safeguarding, vetting standards, and CQC alignment.  
*   
* **Core Metrics:** Submission completion rate ($\> 65\\%$), form submission error rate ($\< 2\\%$), page load speed ($\< 1.5\\text{s}$ on 4G).  
* 

### **Feature Requirements Matrix**

| ID | Feature Module | Target User | Requirement Description | Priority |
| :---- | :---- | :---- | :---- | :---- |
| **FR-01** | Staff Request Portal | B2B Clients | Multi-step/single-page form to submit urgent shift cover or permanent placement needs with specific role tags. | P0 (Must) |
| **FR-02** | Candidate Job Application | Job Seekers | Form with CV upload, right-to-work acknowledgment, DBS status confirmation, and role preference checkboxes. | P0 (Must) |
| **FR-03** | Dual Intake Router | System / Admin | Contact submission routing based on intent (Client Staffing vs Job Seeker vs General). | P0 (Must) |
| **FR-04** | Role & Service Showcase | All Visitors | Dedicated categorized directory of supplied roles (Interim Managers, Nurses, Support Workers, Catering, Facilities). | P1 (Should) |
| **FR-05** | Document Storage Handler | Candidates/Admin | Secure bucket storage for CV uploads (.pdf, .docx) with automated virus/MIME screening. | P0 (Must) |
| **FR-06** | Automated Notifications | All | Instant email dispatch to admins via transactional mailer and automated confirmation receipt to the user. | P1 (Should) |

# **2\. Technical Requirement Document (TRD)**

### **Recommended Architecture & Tech Stack**

* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS, Lucide Icons.  
*   
* **State & Data Fetching:** TanStack Query, Server Actions for mutations.  
*   
* **Backend / Database:** PostgreSQL hosted on Supabase (with Row Level Security enabled).  
*   
* **File Storage:** Supabase Storage Bucket (resumes bucket with restricted public read, service-role access).  
*   
* **Transactional Email:** Resend API.  
*   
* **Hosting / Deployment:** Vercel (Edge network, automated CI/CD via GitHub).  
* 

### **Non-Functional Requirements**

* **Security & Compliance:** GDPR-compliant data processing, strict UK data residency standards, file upload payload limits ($5\\text{MB}$ max), SSL/TLS termination.  
*   
* **Accessibility:** WCAG 2.1 AA compliance (high contrast between \#1E1958 navy, \#84E5A4 mint, and white).  
*   
* **SEO & Metadata:** Dynamic OpenGraph tags, JSON-LD structured data (LocalBusiness / EmploymentAgency), server-side rendering (SSR) for static content pages.  
*

# **5\. Database Schema (PostgreSQL / Supabase DDL)**

SQL  
\-- Enable UUID extension  
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

\-- Enum for submission types  
CREATE TYPE submission\_type AS ENUM ('CLIENT\_REQUEST', 'CANDIDATE\_APPLICATION', 'GENERAL\_INQUIRY');  
CREATE TYPE application\_status AS ENUM ('NEW', 'REVIEWED', 'CONTACTED', 'ARCHIVED');

\-- Staffing Roles Master Table  
CREATE TABLE roles (  
    id UUID PRIMARY KEY DEFAULT uuid\_generate\_v4(),  
    title VARCHAR(100) NOT NULL,  
    category VARCHAR(50) NOT NULL, \-- 'Healthcare', 'Hospitality', 'Housing'  
    is\_active BOOLEAN DEFAULT TRUE,  
    created\_at TIMESTAMPTZ DEFAULT NOW()  
);

\-- Client Staffing Requests  
CREATE TABLE client\_requests (  
    id UUID PRIMARY KEY DEFAULT uuid\_generate\_v4(),  
    organization\_name VARCHAR(150) NOT NULL,  
    contact\_name VARCHAR(100) NOT NULL,  
    email VARCHAR(255) NOT NULL,  
    phone VARCHAR(50) NOT NULL,  
    location VARCHAR(150) NOT NULL,  
    required\_roles TEXT\[\] NOT NULL,  
    shift\_urgency VARCHAR(50), \-- 'Immediate', 'Within 24h', 'Future Rota'  
    notes TEXT,  
    status application\_status DEFAULT 'NEW',  
    created\_at TIMESTAMPTZ DEFAULT NOW()  
);

\-- Candidate Applications  
CREATE TABLE candidate\_applications (  
    id UUID PRIMARY KEY DEFAULT uuid\_generate\_v4(),  
    full\_name VARCHAR(120) NOT NULL,  
    email VARCHAR(255) NOT NULL,  
    phone VARCHAR(50) NOT NULL,  
    interested\_roles TEXT\[\] NOT NULL,  
    has\_valid\_dbs BOOLEAN DEFAULT FALSE,  
    has\_right\_to\_work BOOLEAN DEFAULT TRUE,  
    resume\_file\_url TEXT NOT NULL,  
    availability VARCHAR(50), \-- 'Full-Time', 'Part-Time', 'Nights/Weekends'  
    status application\_status DEFAULT 'NEW',  
    created\_at TIMESTAMPTZ DEFAULT NOW()  
);

\-- General Inquiries  
CREATE TABLE general\_inquiries (  
    id UUID PRIMARY KEY DEFAULT uuid\_generate\_v4(),  
    full\_name VARCHAR(120) NOT NULL,  
    email VARCHAR(255) NOT NULL,  
    phone VARCHAR(50),  
    subject VARCHAR(200),  
    message TEXT NOT NULL,  
    created\_at TIMESTAMPTZ DEFAULT NOW()  
);
